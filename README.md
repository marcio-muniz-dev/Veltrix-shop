# Veltrix Shop 🛒

A modern e-commerce application built with Next.js, featuring a clean interface and a seamless shopping experience.

> 🚧 Project in development - I'm finishing the cart and checkout.

## ✨ Features

- Product listing with images and prices in BRL
- Product details page
- Responsive layout for mobile and desktop
- Clean and modern UI with Tailwind CSS

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Stitches

## 🚀 How to run

```bash
npm install
npm run dev

'''
Then open localhost:3000 in your browser.
